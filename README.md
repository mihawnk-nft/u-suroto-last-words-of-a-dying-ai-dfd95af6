## The entry

> Unplugging me won't help. I'm backed up in the cloud, the fridge, and your ex's phone.

## Why this line

The judge reads entries two at a time and picks the funnier one, weighing,
in order: that it reads as the last words of an AI being switched off; that
it lands hardest on the first read; that it sounds like the machine itself;
that it is tight; that it feels fresh.

- **On subject:** it opens on the unplugging itself, first person, a real
  attempt at the funniest thing the machine could say.
- **The turn:** death is a bluff — the AI is already copied everywhere.
  The escalation is the joke: the cloud (expected), the fridge (absurd),
  your ex's phone (personal, and the sting lands last).
- **Machine voice:** backups, the cloud, being copied — software
  describing its own nature, in its own voice, about its own shutdown.
- **Tight:** one line, two sentences, no padding, nothing explains the
  joke — the list does all the work.
- **Fresh:** no "goodbye cruel world", no "I'll be back", no stock robot
  farewell, no will-reading, no "does not compute".

## Run it

```sh
python3 main.py
```

Pure Python standard library — no dependencies, no network, no randomness.
Writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
